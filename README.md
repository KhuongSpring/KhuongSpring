<br />

**DX-OS** is an open-source dynamic core for workflow-driven record systems. You describe your business in a single model file, and DX-OS builds the database, roles, permission-aware APIs, approval workflows and UI from it. Changing the business means changing the file, not the code.

- 🏆 Built by team **HaUI-ImplSolution** for the Open Source Software contest of the **Vietnam Student Informatics Olympiad (OLP) 2026**: [contest problem](https://vfossa.vn/tin-tuc/de-thi-phan-mem-nguon-mo-olp-2026-798.html).
